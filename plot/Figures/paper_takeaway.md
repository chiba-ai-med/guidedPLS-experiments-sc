# Paper Takeaway — guidedPLS-experiments-sc (Fig. 3 contribution)

1. **Guided-PLS is applicable to unpaired scRNA-Seq / scATAC-Seq integration** at the single-cell level, transferring cell-type labels from RNA to ATAC without any paired barcodes.
2. **Cell type is held out as an evaluation label**; guide Z uses only experimentally available covariates (developmental stage and/or germ layer). This is the principled setting where guided-PLS can be evaluated fairly against baselines that also do not see cell-type labels.
3. **Primary benchmark: mouse organogenesis (E8.5–E10.5)**. Guided-PLS produces meaningful structure across multiple guide choices (`stage`, `germlayer`, `stage_germlayer`), with `stage_germlayer` performing best. In its current form it still underperforms Seurat's anchor-based label transfer on accuracy / ARI / NMI — surfacing a clear next-step direction (parameter tuning, alternative guide encodings, or modified input matrices) rather than a final claim of state-of-the-art.
4. **Secondary / robustness benchmark: mouse testis (E18–P6)**. Used to test guided-PLS under a stage-mismatch regime, not as a head-to-head against integration baselines (Seurat/Harmony/Scanorama not run due to fragment-barcode format incompatibility). Here `none` slightly beats `stage_binned`, consistent with the stage mismatch hypothesis.
5. **The Fig. 3 narrative is therefore "applicability + scope" rather than "best-in-class"**: guided-PLS works, behaves as expected when the guide Z is informative vs uninformative, and a shuffled-Z control (Fig 3D, pending) will sharpen the claim.
