# Paper Takeaway — guidedPLS-experiments-sc (Fig. 3 contribution)

1. **Guided-PLS works for unpaired scRNA-Seq / scATAC-Seq integration at single-cell resolution, given an informative coarse guide Z.** Primary benchmark: 10x Genomics 10k PBMC scMultiome (~10k cells, 11 cell types), with `broad_lineage` (T / B / NK / Myeloid / Other) as guide Z and `celltype` (CD4 T Naive, CD8 T Memory, CD14 Mono, ...) as held-out evaluation label. **gPLS_germlayer reaches accuracy 0.609**, beating Harmony (0.317) and Scanorama (0.476), and approaching Seurat anchor-based label transfer (0.867). ARI shows the same ranking (gPLS 0.481, vs Harmony 0.213, Scanorama 0.356, Seurat 0.735).

2. **Cell type is held out as an evaluation label throughout.** Guide Z uses only the broad lineage that one could in practice obtain from FACS-sorting or coarse marker panels. The eval label `celltype` is never used in training for any method. For PBMC, both guide and eval are derived from the same RNA clustering + marker-gene scoring, so there is no taxonomy mismatch artifact (which inflated some baselines on Organogenesis).

3. **gPLS is algorithmically disadvantaged but wins on label transfer; the compute side is the trade-off.** A fair side-by-side requires noting what each method gets:
   - **Latent dimensionality**: gPLS = **5** (bounded by rank of Y = broad_lineage cardinality), Seurat = 30 (CCA), Harmony = 30 (PCA), Scanorama = 100. gPLS works in a latent space **6–20× smaller** than the baselines.
   - **Feature space**: gPLS uses **raw RNA HVGs (3,000)** and **raw ATAC peaks (~140,000)** with no shared coordinate. Seurat / Harmony / Scanorama all use the **Gene Activity Matrix** (~2,200 genes shared between modalities), which itself is a curated, modality-bridged feature space.
   - **Cross-modal supervision**: gPLS receives only the guide Z (broad_lineage). It never sees cross-modal cell-cell correspondences. Seurat builds explicit RNA↔ATAC anchors; Harmony and Scanorama at least share the gene space across modalities.

   Despite operating on a smaller, less curated, more weakly supervised representation, gPLS reaches accuracy 0.609 (vs Harmony 0.317, Scanorama 0.476).

   **However, the compute side runs the other direction.** Fig 3C shows wall time and peak memory measured by Snakemake's `benchmark:` directive: gPLS = 469 s / 21.3 GB, Seurat = 99 s / 7.7 GB, Harmony = 62 s / 8.3 GB, Scanorama = 87 s / 5.6 GB. **gPLS is the most expensive method** because it processes the raw ATAC peak matrix (~140,000 features × 10,000 cells) as a dense matrix, while the baselines all operate on the much smaller Gene Activity Matrix (~2,200 features × 10,000 cells). The current implementation does not exploit ATAC sparsity (≥99% zeros); a sparse-matrix variant would close most of the gap. As reported, this is a present-implementation cost, not an inherent feature of the algorithm — but readers should know the trade-off honestly: **gPLS beats Harmony / Scanorama on accuracy while requiring 5–8× the compute on the current implementation**.

4. **gPLS aligns modalities along the celltype axis, not by mixing them.** The integration footprint differs qualitatively from anchor-based methods. In nearest-neighbour modality-mixing (lower = better mixing; 100% = total separation, 50% = perfect mix), Seurat achieves 63% (it really mixes RNA and ATAC cells in latent space), but gPLS, Harmony, and Scanorama all stay at 97–99% (modalities remain visually segregated). Despite this, gPLS achieves competitive label-transfer accuracy because **same-celltype RNA and ATAC cells end up at the same coordinate along the guide-Z directions** — they do not need to overlap in space, only to be co-located along the celltype axis. This is a structurally different kind of "integration" than anchor mixing.

5. **The framework's regime of validity is set by how the guide Z stratifies the eval label.** When Y is a coarse partition that strictly refines into the celltypes you want (PBMC: broad_lineage refines into celltype subtypes), gPLS recovers strong celltype information through 5 latent dimensions. When Y is poorly aligned with celltype identity (Organogenesis: germ_layer × stage encodes anatomical position more than celltype identity, with 41 fine celltypes spread across only 9 guide bins), gPLS underperforms — best accuracy 0.164 vs Seurat 0.476. This crossover is the central methodological observation: **gPLS shines when the guide Z is a true biological prior over the celltype space**, and degrades gracefully when Y is uninformative for the eval label.

6. **gPLS hits guide-level accuracy without collapsing to it.** When PBMC predictions are collapsed to the broad_lineage axis (the same partition that gPLS used as guide Z), gPLS reaches **0.927 accuracy** — a +32 pp jump from its celltype-level 0.607. Seurat / Harmony / Scanorama only gain +7–9 pp from the same collapse (Seurat 0.867 → 0.955, Harmony 0.317 → 0.390, Scanorama 0.476 → 0.564). The asymmetry is informative: gPLS's errors are concentrated **within broad lineage** (e.g., predicting CD4 T Memory instead of CD4 T Naive, while staying inside the T branch), whereas the other methods make broad-axis mistakes at similar rates. **Crucially, gPLS is not merely degenerating to the guide**: if it were, celltype-level accuracy would collapse to roughly the fraction of the dominant sub-celltype per broad bin (~0.30 for "always predict CD4 T Memory inside T"), but the observed 0.607 is twice that. Sub-broad celltype structure is being preserved through the latent space, just with noise. **Practical implication for users with uncertain fine-grained labels**: when only coarse experimental labels (e.g. FACS-sortable broad lineage) are available with confidence, gPLS using that coarse guide already produces reasonable label transfer at both the coarse and fine grain. This is the everyday use case the framework is built for.

7. **Supplementary control — celltype as guide**: A reference experiment using the eval label itself as guide Z is included in the supplementary. As expected, this gives near-perfect celltype-level prediction; the value of the panel is to show that gPLS uses the guide as intended (no leakage from guide construction independent of guide content). Combined with point 6, this brackets the framework's behavior: coarse-guide → coarse-acc near 1, fine-guide → fine-acc near 1, with graceful fall-off when guide is coarser than the eval label.

8. **Fig. 3 main narrative**: gPLS as a viable middle-ground integration method when (i) the modalities are unpaired, (ii) GAM-style shared-feature construction is undesired (e.g., to avoid information leak from one modality's gene activity proxy), and (iii) a coarse experimental guide Z exists. PBMC scMultiome (Fig 3 main) shows this regime; Organogenesis (Supp) shows the boundary — celltype granularity beyond guide rank causes degradation. The Testis ArchR dataset has been dropped from the manuscript because its barcode format prevents fair baseline comparison and the explanation cost outweighs its narrative value.
